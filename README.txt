# Teacher Quest v1.0
เปิด `index.html` ในเบราว์เซอร์เพื่อเล่น Prototype

- 30 ข้อคละ 5 มาตรฐาน
- Random Mission / Boss
- Explanation + Knowledge + Exam Tip + Trap
- XP / Level / Combo
- Adaptive weighting จากจุดอ่อน
- บันทึกความก้าวหน้าด้วย localStorage
- Mobile-first สำหรับ iPhone/iPad/PC

หมายเหตุ: ชุดคำถามเป็นข้อสอบต้นฉบับสำหรับฝึก ไม่ใช่ข้อสอบจริงของคุรุสภา
