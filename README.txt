Teacher Quest V8 — Stable Mobile Edition

V8 แยก 4 ระบบ:
- เรียน = เนื้อหาเท่านั้น
- กิจกรรม = เกมฝึกคิดเท่านั้น
- ข้อสอบ = เฉพาะคลังต้นฉบับ
- วิเคราะห์ = สถิติเท่านั้น

ระบบตอบ:
- ทีละข้อ
- ไม่มี A/B/C/D/E
- สุ่มตำแหน่งตัวเลือก
- กดตัวเลือกซ้ำ/ยกเลิกเพื่อแก้ได้ก่อนส่ง
- กดส่งแล้วล็อก
- เฉลยคนละหน้า
- แสดงหมวด + ประเภทโจทย์

หมายเหตุ:
ไฟล์ PDF ต้นฉบับในระบบสนทนาปัจจุบันเกิดข้อผิดพลาดจาก file service จึงไม่สามารถตรวจอ่านข้อความเพื่อฝังข้อสอบได้อย่างปลอดภัย ผมจึงไม่แต่งข้อสอบทั่วไปมาแทนไฟล์
