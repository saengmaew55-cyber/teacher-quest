# Teacher Quest V3 — Source Lab

เวอร์ชันนี้สร้างใหม่จาก Teacher Quest V2 โดยเปลี่ยนระบบคลังโจทย์ให้ใช้เนื้อหาจากคลังข้อสอบที่ผู้ใช้แนบเป็นฐาน

## แหล่งข้อมูลที่ใช้
- 863598_ข้อสอบคู่ขนานสำหรับนักศึกษา.pdf — ใช้เป็นแหล่งข้อความ/โครงสร้างโจทย์หลักใน V3
- 2567.pdf — เก็บเป็นแหล่งอ้างอิงในโปรเจกต์เดิม; ไฟล์นี้เป็น PDF สแกน จึงยังไม่ได้ดึงข้อความมาใส่เป็นข้อโดยอัตโนมัติในรอบนี้
- จำลอง.pdf — เป็น PDF สแกนที่ระบบอ่านข้อความไม่ได้ในรอบนี้ จึงยังไม่ดึงข้อความมาใส่เป็นข้อโดยอัตโนมัติ

## สิ่งที่เปลี่ยน
- ไม่มี A/B/C/D/E
- สุ่มตำแหน่งตัวเลือกทุกครั้ง
- ไม่มีระบบถาม “เดาหรือไม่”
- มี Source Questions จากคลัง
- มี Adapted Questions ที่ต่อยอดจากแนวคิดในคลัง
- เฉลยทันทีพร้อมเหตุผลและเทคนิค
- จำข้อที่ผิดด้วย localStorage
- โหมด เล่นต่อ / Daily 8 / ทบทวนข้อพลาด
- คละเนื้อหาโดยไม่แสดงหมวดให้ผู้เล่น
- ใช้งานบนมือถือ/iPad และ GitHub Pages ได้โดยไม่ต้องมี backend
