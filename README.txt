Teacher Quest Master Question Bank

นำโฟลเดอร์ data ไปวางในเว็บเกมได้เลย
- questions.json = ฐานข้อมูลหลัก
- questions.csv = สำหรับ Google Sheets/Excel/นำเข้าเครื่องมืออื่น
- questions.js = โหลดตรงในเว็บแบบ static
- categories.json = รายการ 5 หมวดและจำนวนข้อ
- manifest.json = สถิติและสถานะแหล่งข้อมูล
- docs/extraction_report.md = รายงานการถอด

หมายเหตุ: ข้อสอบจากไฟล์ที่ไม่มีเฉลยจะเก็บ answer_index เป็น null และไม่เดาเฉลยให้เอง
